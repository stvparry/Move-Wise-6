# MoveWise 8 Next Chapter Edition
Fresh repository build. Upload `streamlit_app.py`, `requirements.txt` and this README to the repository root and deploy `streamlit_app.py`.

V8 adds 0–3, 3–8 and 8–15 year fit assessments, stay/final-move/maintenance/stairs/future-car/guest inputs, user-supplied live-listing analysis, and an optional PropertyData asking-price connector.

## Optional PropertyData connector
In Streamlit Community Cloud, add a secret named `PROPERTYDATA_API_KEY`. Do not put the key in GitHub. Asking-price evidence requires a full postcode and is labelled as licensed API evidence. Coverage depends on the provider response.

Report filename: `movewise_8_next_chapter_report.html`.
